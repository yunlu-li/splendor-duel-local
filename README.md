# 璀璨宝石对决 网页版

机器人策略已支持休闲/竞技难度、即时胜利和公开威胁防守。实现与验证方法见 [机器人策略说明](docs/bot-strategy.md)。

一个可以直接在浏览器里玩的《璀璨宝石：对决》网页原型。适合一个人和机器人练习，也适合同一台电脑上两个人轮流对战。

> 本项目是个人学习和试玩原型，不包含官方素材，也不用于商业用途。

## 直接开玩

打开这个地址即可进入游戏：

```text
https://yunlu-li.github.io/splendor-duel-local/
```

推荐第一次先选 `与机器人对战`，不需要找人，点进去就能开始熟悉流程。

## 可以玩什么

- `与机器人对战`：你操作一方，机器人自动行动，适合一个人试玩。
- `本地双人对战`：同一台电脑、同一个浏览器里两个人轮流操作。

当前只开放上述两个模式。好友房入口已隐藏，相关实验代码暂存，尚未修复或作为可用功能交付。

## 怎么操作

- 点击棋盘上的宝石来选择 token。
- 点击 `拿已选 token` 拿走选中的宝石。
- 有特权时，选中 1 个非黄金 token 后可以点击 `花特权拿 1 个`。
- 点击市场卡下面的 `买` 打开支付面板。
- 点击市场卡下面的 `留` 保留该卡并拿黄金。
- 点击牌堆区域的 `盲保` 保留对应等级的牌堆顶牌。
- 自己的保留区会显示具体卡牌、购买按钮和资源缺口。
- 对手的保留区只显示保留数量，不显示具体卡牌。
- 点击已购买卡或自己的保留卡，会在右侧显示完整卡牌详情。

## 游戏目标

按照《璀璨宝石：对决》的常见胜利条件推进：

- 总威望达到胜利要求。
- 单色威望达到胜利要求。
- 收集足够皇冠并获得皇室卡。

页面顶部会显示当前回合、阶段和双方分数信息。

## 网页版说明

在线试玩版是静态网页，不需要安装任何东西，也不需要注册账号。它可以玩机器人模式和本地双人模式。

这两个模式均在浏览器内运行，不需要房间服务器。页面不会连接好友房服务，旧邀请链接也只会进入模式选择页。

## 常见问题

### 打不开网页

先确认地址是：

```text
https://yunlu-li.github.io/splendor-duel-local/
```

如果页面刚发布或刚更新，GitHub Pages 可能需要等 1-2 分钟刷新。

### 如何切换机器人难度

进入机器人模式后，在顶部选择“休闲”或“竞技”。机器人计算时不能替它行动；如果计算失败，可点击“重试机器人”，保留当前对局。

### 不知道第一步该做什么

选 `与机器人对战`，然后从棋盘拿宝石。资源够了以后，点击市场卡下面的 `买` 购买卡牌。

## 本地运行

安装 Node.js 24.x。项目的运行环境、依赖锁定和持续集成均以该版本为准。

会用 Git：

```bash
git clone https://github.com/yunlu-li/splendor-duel-local.git
cd splendor-duel-local
npm ci
npm run dev
```

不会用 Git：

1. 打开项目页面：`https://github.com/yunlu-li/splendor-duel-local`
2. 点击绿色 `Code` 按钮。
3. 点击 `Download ZIP`。
4. 解压 ZIP。
5. 用终端进入解压后的文件夹。
6. 执行：

```bash
npm ci
npm run dev
```

然后打开：

```text
http://localhost:5173/
```

运行 `npm run dev` 的终端窗口要一直开着。开发模式无需启动 `src/server` 或任何房间服务。

## 当前范围

本地双人模式由两人轮流操作同一浏览器；机器人模式固定玩家为 P1、机器人为 P2。对手保留牌在面板、提示和保留日志中隐藏。

好友房服务端和旧辅助脚本仅作为后续开发资料保留，当前不提供邀请、连接或联机玩法。
